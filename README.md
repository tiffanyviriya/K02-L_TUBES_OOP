🍳 Nimonscooked - Tugas Besar OOP

Nimonscooked adalah permainan simulasi memasak berbasis Java yang dibuat untuk memenuhi Tugas Besar mata kuliah IF2010 Pemrograman Berorientasi Objek.

Pemain harus menyiapkan bahan, memasak, dan menyajikan hidangan sesuai pesanan dalam batas waktu tertentu.

🎮 Cara Bermain

Tujuan utama adalah menyajikan pesanan sebanyak-banyaknya tanpa membuat makanan gosong atau marah pelanggan.

Kontrol Keyboard

Tombol

Fungsi

Keterangan

W, A, S, D

Gerakan

Bergerak ke Atas, Kiri, Bawah, Kanan

V

Action

Melakukan aksi (contoh: memotong bahan, mencuci piring)

C

Interact

Berinteraksi (contoh: mengambil/menaruh item)

B

Switch

Mengganti stasiun/karakter (jika mode switch aktif)

L

Dash

Berlari cepat untuk waktu singkat

T

Throw

Melempar bahan (hati-hati mengenai teman!)

🚀 Cara Menjalankan

Menggunakan IDE (IntelliJ / Eclipse / VS Code)

Buka folder proyek ini di IDE Anda.

Tunggu proses sync Gradle selesai.

Jalankan file utama: src/main/Main.java.

Menggunakan Gradle (Terminal)

Jika Anda memiliki Gradle terinstal, jalankan perintah berikut di root folder:

./gradlew run


🛠️ Tech Stack

Bahasa: Java (JDK 21 disarankan)

GUI Library: Java Swing / AWT

Build Tool: Gradle

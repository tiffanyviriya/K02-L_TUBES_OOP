<!--StartFragment--><h1 data-pm-slice="0 0 []">🍳 Nimonscooked - Tugas Besar OOP</h1><p><strong>Nimonscooked</strong> adalah permainan simulasi memasak berbasis Java yang dibuat untuk memenuhi Tugas Besar mata kuliah IF2010 Pemrograman Berorientasi Objek.</p><p>Pemain harus menyiapkan bahan, memasak, dan menyajikan hidangan sesuai pesanan dalam batas waktu tertentu.</p><h2>🎮 Cara Bermain</h2><p>Tujuan utama adalah menyajikan pesanan sebanyak-banyaknya tanpa membuat makanan gosong atau marah pelanggan.</p><h3>Kontrol Keyboard</h3>
Tombol | Fungsi | Keterangan
-- | -- | --
W, A, S, D | Gerakan | Bergerak ke Atas, Kiri, Bawah, Kanan
V | Action | Melakukan aksi (contoh: memotong bahan, mencuci piring)
C | Interact | Berinteraksi (contoh: mengambil/menaruh item)
B | Switch | Mengganti stasiun/karakter (jika mode switch aktif)
L | Dash | Berlari cepat untuk waktu singkat
T | Throw | Melempar bahan (hati-hati mengenai teman!)
